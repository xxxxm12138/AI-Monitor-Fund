# 供给侧建模 · AI 前沿赛道全景与监测口径

> **为什么这么做** — 要把"AI 发展"落到可投资的票,先得说清"我们到底监测 AI 发展的哪些赛道",否则会退化成"给某只股票找理由"。
> **思路** — 先划监测口径(能力前沿 + 产业链两义合一),再用两条正交轴(价值栈 × 成熟度)把 AI 发展铺成全景,叠上前沿向量与中国侧 edge。
> **目标** — 产出一张"AI 发展供给侧全景",作为后续所有映射的**节点池**;它不依赖选哪只票,可先建、可复用。

---

## 一、口径:先定边界,再列清单

**监测对象定义**:"AI 发展" = 两件事的合流——

1. **能力前沿(capability frontier)**:AI 能做什么、边界在哪、往哪迁移(scientist 视角);
2. **承接与变现这条能力的产业链(value chain)**:谁供算力 / 数据 / 模型、谁部署、谁买单(投研视角)。

**为什么两块必须合一**:只看产业链,会漏掉还没大规模变现、但会重排格局的范式迁移(世界模型、具身、AI4S);只看能力前沿,又落不到可投标的。两块合一,才能既"追踪 AI 发展"又"落到 ticker"。

**组织原则(两条正交的轴)**:
- **纵向 = 价值栈**(AI 在哪变现):L1 硬件 → L6 具身(§二)。空间轴。
- **成熟度 / 时间轴**(信号多早):研究前沿 → 创业 / 一级 → 商业化 / 二级(§三)。其最左端「早期信号层」最领先,是一等监测对象,不是某层的属性。

**排除项(口径的负空间)**:
- **AI-washing**:贴 AI 标签但不改变竞争格局的传统公司——不进核心;若另类数据能证伪其 AI 叙事,单列进做空侧。
- 与 AI 能力无因果的纯主题炒作:不进。
- 一级纯早期、无可观测信号的项目:进「早期信号层 / 未来机会雷达」,给方向不给下注。

**第一性锚点**:AI 发展的驱动 = scaling(compute × data × algorithm)+ 范式涌现。所以口径的"能力面"要能捕捉这两者的**拐点**,而不只是记录发布会。

## 三、成熟度轴与「早期信号层」

价值栈回答"在哪变现",成熟度轴回答"信号多早"。**最左端 = 早期信号层**,最领先、独家性最高,单列为一等监测对象,横切所有六层。共性:领先二级几个季度到几年;给方向与范式、不给量级;量大到人读不过来,**必须 AI 筛**。三条子流:

- **子流 A · 研究前沿(最早)**:arXiv / 顶会论文计量与主题迁移、benchmark 榜突破、开源模型发布、顶 lab 博客。读法 = 主题聚类的斜率变化 = 范式拐点最早信号。
- **子流 B · 创业与一级**:新公司成立、种子—B 轮融资、顶级 VC portfolio、赛道资金流。读法 = 钱往哪个赛道涌 = 主题轮动领先指标;公开龙头出现 well-funded 挑战者 = 做空预警。
- **子流 C · 人才与资本流向(贯穿)**:顶尖研究员流向、明星团队 spin-out、LP → VC 资金流。读法 = 最领先的动量信号——最好的人去哪,哪个方向就在起。

**定位(必须讲清)**:早期信号层产出 = watchlist / 方向 / 范式预警,喂研究员信心,**不直接下注**;成熟层(近 ticker、可回测、进 nowcast)决定下多少注。**早期层管"往哪看",成熟层管"下多少注"**,两者互补。

## 四、横向:五个前沿向量(能力 / 范式往哪走)

横切所有层,是"能力面"要持续判断的拐点:

1. **Scaling 是否还起效**:预训练堆料边际递减了吗?直接决定 L1 / L2 需求持续性。
2. **推理时计算 / 效率 / 端侧**:改变算力需求结构(训练 → 推理迁移),也改变 L6。
3. **新范式**:世界模型、具身 / VLA、AI4S、multi-agent——还没大规模变现但会重排 L3 / L5 / L6,是「未来机会雷达」主料。
4. **开源 vs 闭源格局**:开源追赶速度,决定模型层价值分配与"自训小模型"可行性。
5. **数据飞轮 / 护城河迁移**:价值从模型往数据 + 分发迁移——决定 L4 / L5 谁有真护城河。

## 五、每层监测三面 + 信息源漏斗

**三面(what)**:① 能力 / 技术进展(paper / benchmark / 发布);② 产业 / 商业进展(收入 / capex / 订单 / 部署 / 融资);③ 参与者动态(who:lab / 大厂 / 创业 / 人才 / VC 钱流)。

**信息源漏斗(顶 → 底,越往下越接近可交易信号)**:
- 顶层 **科研源**(= 早期信号层 A):arXiv / 顶会、GitHub / HuggingFace、benchmark 榜、lab 博客 → **给方向**。
- 中层 **商业源**:融资、招聘 JD、云厂 capex 指引 / 电话会、发布 / PR、专家访谈 → **给量级**。
- 底层 **终端源**:App 活跃 / 下载、电商销量、招投标 / 采购、海关、舆情 → **给验证**。

**成熟度 gate**:科研信号给方向,商业信号给量级,终端信号给验证;**三层打架本身是信号**。

## 六、中国侧(差异化的落点)

每层里"真 KPI 由中国决定 / 中国地面数据能领先海外分析师"的节点,是团队的中国地面数据 edge:

- **L1**:国产芯片进度、光模块(中际旭创 / 新易盛 / 天孚)、存储链、数据中心电力与散热、CoWoS 中国配套。
- **L2**:中国 AI 服务器(SUPX 类)、云厂 capex 的中国侧读出。
- **L3**:DeepSeek / Qwen 开源生态采用与出海。
- **L5 / L6**:中国 AI 应用出海真实留存 / 收入、消费电子 / 自驾 / 机器人 / AI 眼镜的中国供应链(多上市、可观测,最肥的中国地面数据节点)。
- **早期信号层**:中国一级 sourcing(IT桔子 / 烯牛)+ 中国 lab / 开源社区动态。
- **医疗器械范式(STAAR 类)**:虽非 AI,但"美股上市、真 KPI 由中国决定"的方法论样板属同一 edge。
