# 18 · 信息架构规格：四个一级栏目（2026-09-20 · 她已确认「ok」· v12 已按此实装）

原则：L1 按 PM 一天的决策顺序排（先处理变化 → 再看时间线 → 再看自己的票 → 最后做研究），每个 L1 内部只有一种信息形状；L2 = 同一形状下「行是什么」不同。所有派生字段只用现有五张表（指标 75 · 观测记录 173 · 边 35 · 日历 58 · 关键事实 57）+ 13F，窗口与排序分为设计选择（🔵 仅排序，不进阈值）。

## L1-1 信号（默认落地页）

形状：事实 × 优先级。场景：周一早盘 5 分钟，「上周什么变了、这周要盯什么」。为什么在 L1：它是 PM 每天第一个问题，且不是日历的子集——日历按时间排，这里按「对我的书重要程度」排，两者的行序不同。

| L2 | 场景 | 点进去 | 推断逻辑 |
|---|---|---|---|
| 方向变化 | 上周有哪些观测在推 / 拆我的 thesis | 一行一条：日期 · 方向 chip（加强 / 削弱 / 待判断）· 实体 · 一句话事实（值 + 备注 ≤ 60 字）· 打到哪些票（权重）· 来源级（非一手才显示）· 跳转（日历行 / 票页） | 取观测记录中 direction ∈ {↑,↓,!} 且 0 ≤ as-of − knowledge_time ≤ 7 天（可切 30 天）；排除 prior / position / computed 类型。方向本身是 A11（B 级判断，未复核前只用于排序显示）。排序分 = Σ_{该指标出发的边}（到票的 13F 权重 × 边星级 ★1–3）；票自身指标按 ★3 计。同分按 knowledge_time 降序，再按一手优先。排序分登记 A12（🔵 仅排序）|
| 对指引偏差 | 谁超了 / 没达到公司自己说的数 | 一行一条：实体 · 期间 · 实测 · 指引 / 目标 · 偏差 % · 方向 · 跳转 | 同一指标、同一实体、同一期间下同时存在 obs_type = actual 与 guidance / target 的记录；两者可解析为数字时 偏差 = (实测 − 指引) / 指引，指引为区间取中点（登记 A14）；不可解析时只并排显示不算 %。按 |偏差| 降序，再按权重。没有指引的指标不出现——不用一致预期，因为我们没有一手一致预期源 |
| 临近排期 | 这两周有什么要来 | 一行一条：日期（距今 n 天）· 事件 · 日期依据（非公司公告才标「推定 / 估计」）· 打到哪些票 | 日历表中 dated 且 0 < date − as-of ≤ 14 天，按日期升序；依据来自 basis 列（公司公告 / 规则推定 / 估计 / 待定，C9）|
| 底部一行 | 诚实说明 | 证伪条件 3 条（NBIS / RBRK / FCEL，B 稿）· 状态一律「不可判：阈值待定（C6）」· regime 定性「同向偏多」为 doc 28 占位 | 不做「破阈值」信号：阈值是 D 级未定，🟠 类不进阈值（doc 30 闸门）|

## L1-2 日历

形状：事实 × 时间。场景：「什么时候来、刚发生了什么」，按时间线扫。为什么在 L1：时间是 PM 的第二个坐标，且每种行类型列不同，需要自己的一级空间。

行类型规则（一条日历行进哪个 L2）= 记录类型 × 节点角色 × 层，58 行全部落位：

| L2 | 规则 | 行数 | 列 | 场景 |
|---|---|---|---|---|
| 本周（默认） | 全部类型，窗口 = 近 14 天 + 未来 30 天（as-of 固定时 ±7 天几乎为空，实装放宽；实时管线下可收回 ±7） | — | 日期 · 类型标签 · 名称 · 要点（按类型换形式）· 对持仓 | 一屏看混合时间线 |
| 数据 | obs_type ∈ {actual, prior, guidance, computed} × 角色 = 领先指标 × 层 = 产业确认层（含同业 CoreWeave） | 15 | 层 · 地区 · 重要 · 指标（实体 · 期间）· 实测 · 预期 / 指引 · 上期 · 变化 · 对持仓 | 产业与 AI 读数，对标 TV Economic |
| 财报 | obs_type ∈ {actual, guidance, prior} × 角色 ∈ {公司数据, 仓位} × 层 = 公司数据层 | 18 | 票（权重）· 期间 · 营收 实测 / 指引 / 上期 · YoY % · 关键 KPI · 电话会语气 · 下次 | 核心票与尾仓季报，对标 TV Earnings |
| 事件 · 政策 | obs_type ∈ {event, state} × 角色 ∈ {事件, 政策, 公司里程碑} | 16 | 类型 · 事件 · 发生了什么 · 相关方 · 状态 · 对持仓 · 来源级（非一手才显示） | 融资 / 合同 / 产能 / 政策，事实型无数值列 |
| 前沿 | 角色 ∈ {前沿, 观点} 或（领先指标 × 层 = AI 发展层，如定价） | 9 | 日期 · 类型（发布 / 定价 / 榜单 / 顶会 / 论文）· 主体 · 主张 · 来源级 · 判断（D 级，未判显示待判）· 对持仓 | 过闸的前沿动态；读数进顶部读数带 |

列的推断：
- 实测 / 预期 / 上期：直接取当日记录（value + unit）；预期只取 guidance / target 记录，不放我们的预测。
- 变化：同实体同指标，有上期记录且两者为数字 → YoY = (实测 − 上期) / 上期；有指引 → vs 指引 %；否则「—」。现有上期值约 1/3 的数据行，不造数。
- 方向 chip：记录级 direction（A11）。
- 重要（三档柱）：该节点出发边的最高星级；无边则 D1 / D3 / D7 = H，D5 / D6 = M，其余 L；核心票自身 = H（A1 / A2，只排序）。
- 层：AI 发展层（D2–D7）/ 产业确认层（D1）/ 公司数据层（持仓侧）。
- 筛选条（页内 L4）：时间 · 层 · 影响持仓 · 地区（中国侧）· 搜索；预设（持仓链 / 前沿）= 保存的筛选组合。

## L1-3 持仓

形状：对象 × 属性（N 个票 × 一个时点）。场景：「我的票现在什么状态」，日均访问最高。为什么在 L1：使用频率最高，且行 = 票，与日历（行 = 事实）形状不同。

L2 = 组合 · NBIS · RBRK · STAA · FCEL · 尾仓（8 只）。

持仓表（L1 落地）列与推断：

| 列 | 推断 |
|---|---|
| 权重 | 13F 2026Q2 position 记录（xlsx，P1） |
| 上游供给 / 下游需求 / 政策环境 | 60 天内，该票 供给边（+ 自身指标）/ 需求边 / 政策边 的来源指标记录的方向聚合：↓ 当 n↓ ≥ max(n↑, 1)；否则 ↑ 当 n↑ > 0；否则 →；任何 ! 追加 !；无记录「—」（agg 规则，设计选择） |
| 本周 | 7 天内、关键边（有 ★）或自身指标、方向 ≠ → 的记录，按星级再按时间取第一条：侧别 + 方向 + 实体 |
| 风险 | 60 天内，在「预警占优边（预警分 ≥ 可交易分）∪ 政策边 ∪ 竞对边 ∪ 自身指标」上方向 ∈ {!, ↓} 的记录数；若自身记录含口径警示（合同电力 ≠ 并网、承诺 ≠ backlog）再 +1 |
| 领先 | 90 天内，可回测 / 结构成立（T1 / T2）的供给、需求边聚合方向；标出最高层级 |
| 下一个数据点 | 该票相关指标的最近一条未来日历行，优先 财报 / 目标 / 截止；显示距今天数与日期依据 |

行 hover：该票的上游链（从边表取 to_ticker = 票的边，按侧别分组）。

票专页（L2）三层折叠：
- 决策层：一句状态（关键事实表 status_line，B 稿）· 权重 · 三色块（供 / 需 / 政）· 综合判断表盘（定性，C6 未定）· 本周 · 证伪条件（B 稿，状态不可判）
- 支撑层：AI 发展 → 本票阶梯（见下）· 公司数据字段表（值 · 期间 · 方向 · 指引）· 证据结构（边按侧别 / 可信层 / 独家性 / 层计数）· 120 天时间条（该票相关未来日历行）· 关键事实简报
- 运维层：观测记录表（一行一个事实）· 来源 P 级 · 分工 · 可得 · 假设 ID

阶梯推断（每票）：级序 能力前沿 D5 → 范式成本 D6 → lab 资金 D3 → 数据 D2 → 人才 D4 → 政策 D7 → 产业确认 D1 → 公司数据；每级取「到本票、来源指标在该维度」的边，状态 = 这些指标记录在窗口内的方向聚合（AI 层 120 天、产业 / 公司 90 天）；可信 = 该级边中最高层（T1 可回测 > T2 结构成立 > T3 方向级）；独家性 = 边的独家性标签；附最新两条数据点。中间机制节点为 A10（结构先验）。

组合页：13 只权重与操作、总值、换手 80.30%、AI / 非 AI 分组（核心 / 非 AI / 尾仓）、前四集中度、13F 下次截止（C13）。没有价格与收益归因——无行情源，不做。

## L1-4 研究

形状：混合（低频深度），相当于 TV 的 More。场景：研究员做复盘、梳理链路、核来源；日均 0–3 次。为什么在 L1：低频但必须可达，且不该占高频入口的位置。

|---|---|---|---|
| AI 发展专页 | 「AI 走到哪一级了」，扣题之页 | 顶部读数带 4 格（AA 指数 · 训练算力增速 · 开源差距 · cost-per-token：当前值 + 更新时间 + ≥3 点画折线）· 全局阶梯 · 过闸动态（近 90 天前沿行）· 顶会与发布排期 · 全图 · 缺口灰字（论文斜率待建 · 新范式待填 · D4 合规） | 全局阶梯 = 每级取该维度出发的**全部**边（不限票），状态聚合同上；活跃边 = 来源指标 60 天内有 ↑ / ↓ / ! 记录（登记 A13），全图默认只亮活跃边、其余灰 |
