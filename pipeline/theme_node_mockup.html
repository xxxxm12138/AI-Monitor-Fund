怎么读这张:5 条不同类型的信号(论文/博客/采用/融资/人才)本身都没有"值",但它们聚成一个主题、且 30 天内在加速 —— 这个"加速"才是被监测的信号。谁都过不了双闸单独外溢,但主题动量够了会整体外溢成一条 T3 方向边。点任一条 → 原文 anchor;点"→NBIS" → 传播图里那条多跳边。
归置规则(一句)：idea 级信号不建指标、不挂票，建/挂到「主题节点」，当它主题时序里的一个 anchor 点。
  • 单位是主题,不是指标:一篇论文/一个博客/一次跳槽 = 主题下一个点;信号 = 主题的斜率(加不加速)。
  • anchor-only 记录:fct_frontier/event,score 留空,只存 思想摘要 + 源 + 立场 + 可验证 + 类型(论文/博客/采用/融资/人才)。
  • 无处安放 = 补主题:分类器挂不上现有主轴 → 新建主题节点(如"决策模型范式"),这是 complete-by-construction。
  • 两道闸照走,但外溢的判据是主题级(斜率×含金量×影响力),不是单条;默认 watchlist / 方向。
  • schema 增量:topic_cluster 从 fct_frontier 的一个字段,升成一等「theme 节点」(带 主轴归属 / 斜率 / 双闸聚合 / 外溢状态)——和我们给传播图升机制节点同一个做法。
